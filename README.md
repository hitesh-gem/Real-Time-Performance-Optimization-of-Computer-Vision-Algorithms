A production-ready Python pipeline demonstrating model profiling, magnitude-based unstructured pruning, post-training dynamic quantization, and performance benchmarking using PyTorch and MobileNetV2.
Designed to optimize lightweight convolutional neural networks (CNNs) for resource-constrained edge devices, pushing inference speed past the real-time threshold ($\ge 30$ FPS) with minimal impact on classification accuracy.
Baseline Profiling: Measures baseline inference latency, throughput (FPS), and disk size using PyTorch.Structural Sparsity (Pruning): Implements L1 unstructured weight pruning to eliminate redundant parameters across convolutional layers.Post-Training Dynamic Quantization: Converts high-precision $FP32$ weights in linear classifier blocks to low-precision $INT8$ format for accelerated CPU integer arithmetic.Automated Benchmarking: Compares performance metrics side-by-side to quantify latency reduction and throughput gains.
Model Profiling & Bottleneck Identification: Analyzed memory bandwidth saturation caused by high-precision floating-point weights and heavy matrix multiplications in standard CNN layers.
Magnitude-Based Unstructured Pruning: Pruned 20% of connection weights with the smallest L1 norms across all nn.Conv2d layers to induce structural sparsity.
Dynamic Quantization: Applied post-training dynamic quantization to convert FP32 linear layers to INT8, significantly lowering memory footprint and execution latency on CPU hardware.
